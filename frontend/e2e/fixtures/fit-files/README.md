# FIT File Fixtures

This directory contains pre-built FIT files for E2E testing.

## CP Model Test Files

Files prefixed with `cp-ride` are designed to produce **CP=220W, W'=15000J** when
analyzed together using the 2-parameter critical power model.

Formula: `P(t) = CP + W'/t`

| File | Peak Duration | Peak Power | Description |
|------|---------------|------------|-------------|
| cp-ride1-2min.fit | 2 min | 345W | 2-min all-out effort |
| cp-ride2-5min.fit | 5 min | 270W | 5-min threshold effort |
| cp-ride3-10min.fit | 10 min | 245W | 10-min tempo effort |
| cp-ride4-20min.fit | 20 min | 233W | 20-min FTP-style effort |
| cp-ride5-mixed.fit | 3 min | 303W | Long ride with mixed efforts |

### Expected Peak Powers (P = 220 + 15000/t)

- 2 min (120s): 345W
- 3 min (180s): 303W
- 5 min (300s): 270W
- 10 min (600s): 245W
- 20 min (1200s): 232W
